# Espace de préparation FILNEXIA Digital

Cet espace est un atelier de travail privé au niveau du dépôt (branche `brand/filnexia-preparation`) pour préparer une éventuelle identité de marque.

- `BRAND-IDENTITY-DRAFT.md` : plateforme de marque, architecture, palette, textes et liste de validation.
- `assets/filnexia-logo-concept.svg` : proposition de logo vectoriel éditable.
- `assets/filnexia-favicon-concept.svg` : proposition de favicon.

**Important :** ces éléments ne sont pas publiés sur le site actuel. La disponibilité de FILNEXIA n'est pas juridiquement confirmée. Ne pas fusionner cette branche dans `main` avant vérification OAPI/OIPI et validation finale.
